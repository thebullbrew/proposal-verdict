The Method

All-in cost is advisor fee + fund expenses + other/trading costs. Net return is gross return minus all-in cost. Ending wealth is portfolio × (1 + net return)years. Payback is switching cost divided by annual dollar savings. Risk is aligned when a portfolio score sits within 10 points of the prospect's tolerance.
